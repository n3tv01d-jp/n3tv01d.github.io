Building a Network Attached Storage with Samba

Written by N3TV01D | Published September 22, 2026

Backups backups and even more backups

Having a cloud server is nice for backups of all different kinds. Something that functions like a cloud service but without a lot of the nonsense is a NAS (Network Attached Storage). I want to make my own (instead of spending God knows how much money) so I can easily transfer files between multiple desktops and laptops. With the WireguardVPN I am even able to access my NAS from outside my network.

The main reason for me having a NAS would be to transfer all of my fully rendered music to a Windows desktop so I can edit music videos. Most software these days is strictly released on Windows and Apple products, not linux. I managed to get FL Studio running inside of Wine (Linux Windows Compatibility Layer) but things like Sony Vegas and Adobe After Effects don't seem to work unfortunately.

The First Step

Today we are building a NAS on an Arch Linux installation due to its low resource usage. We start by installing samba with the command sudo pacman -S samba

Now we have to enable the service using sudo systemctl enable --now smb. After that we copy the default configuration using sudo cp /etc/samba/smb.conf.default /etc/samba/smb.conf

Mounting a Drive

The main drive that hosts the Arch Linux OS only has 120GB of space. This is waaaaaay to little for the nearly 700GB of music projects that I currently have.

With lsblk I can see what other drives are installed inside the system. I connected 2 drives, a 1TB drive and a 500GB drive.

  • I have a drive named sdb (the terrabyte drive) which I mounted on /samba
  • The second drive is sdc1 which is mounted on the /samba2 folder

We also need to make a username and password which can be done through the following commands:

  • sudo useradd -m username
  • sudo smbpasswd -a username
  • sudo smbpasswd -e username
  • Replace the word username with the username you want to use ofcourse

Final Steps

Now all we have to do is mount the NAS to our main system. In the file explorer of your operating system you can connect through the network tab. In my case I connect to smb://192.168.178.205. Now I enter my username and password and I am good to go.
