Nextcloud Self-Hosted Cloud Solution

Written by N3TV01D | Published September 22, 2026

The Magic of Prepackaged Installations

I like to have my files backed up somewhere safe, just in case of anything going wrong (especially my FL Studio projects). Apps like Dropbox, Google Drive and Mega.co.nz are great but I don't trust my data on someone else their computer. The cloud sounds so magical but your data is still in someone's possession. Today I am going to fix that

I have tried installing Nextcloud in a couple different ways, none worked except for one. When installing Ubuntu Server for the first time I noticed Nextcloud being available for installation, which did seem to work for me. I don't know why or how but any other method didn't seem to work even hours after troubleshooting.

The First Step

When configuring the Ubuntu Server install we are able to select the (presumably snap) package for Nextcloud. Selecting this package automates the install and takes away a lot of the headache you would have trying to manually install it.

Configuring Nextcloud

Once Ubuntu Server is done installing (including the prepackaged Nextcloud installation) we can browse to the web interface on a different computer. The web interface is being hosted on the device's local ip and port 80.

  • You need to create an admin account on first startup.
  • And then everyting just works, its that simple.

There are also plugins you can install from the admin menu which comes in pretty handy. I have backup all of my music projects including the rendered wav and mp3 files. With the music plugin I can play everything straight from the "cloud".

This was probably the easiest installation I have done so far, way better then trying to install it manually which costed me multiple hours and a lot of headache and no results.
