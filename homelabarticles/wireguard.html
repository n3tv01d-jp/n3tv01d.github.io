Wireguard VPN Tunnel

Written by N3TV01D | Published September 22, 2026

A Nice Gift

A while ago, my neighbor gave me 2 knock-off Raspberry Pi's which he didn't know how to use. It were 2 RockPi 4B+ SBC's that had to be flashed in a very specific way that even the documentation on the official website didn't cover correctly and fully. This seemed like a fun challenge to me since I wanted to use at least one of them as a VPN so I could enter my network while I was somewhere else.

The most difficult part of setting up these RockPi's was the flashing of the emmc chips that are soldered onto the board. According to the documentation I should've been able to run anything from a microsd card but that didn't seem to be working. Setting up the VPN software itself was pretty easy since there is a project called PiVPN (which also works on non-Pi devices and inside docker containers). Today we will be looking at this FOSS Project and try to make it work.

The First Step

After flashing the RockPi and configuring login credentials, locals and network we simply follow the one-line instructions from the official PiVPN website: https://www.pivpn.io/

Make sure you give the device a static ip inside the router and forward the udp port 51820 on this device so you can connect from outside of your network.

Configuring the device

After executing the command curl -L https://install.pivpn.io | bash we are greeted by the installation screen. Here we want to configure the device to use Wireguard (which is in my opinion easier to use on mobile devices thanks to the Wireguard App). Having configured the software we can now enter pivpn -h inside the terminal to get a list of commands we can use. The most interesting ones for now are:

  • pivpn -a (This is to add a client)
  • pivpn -qr (This will render a scannable QR code that you can scan with your phone using the Wireguard App to instantly create a connection)

The Last Steps

Now that we have setup the VPN there is only 1 thing to do: test the connection.

Turn off the wifi on your mobile device (or connect to a different network) and turn on the Wireguard VPN. You can use websites like whatsmyip to see if everything is setup correctly.
