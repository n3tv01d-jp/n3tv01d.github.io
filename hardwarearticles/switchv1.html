Nintendo Switch V1 Modding

Written by N3TV01D | Published September 22, 2026

Faulty From The Start

I love the Nintendo Switch and it's collection of games, but the main menu theme is lackluster, there is no menu music, some games can easily run 60fps but are stuck on 30fps and I like having full control over my devices so I can use them how I see fit. For this reason I bought a V1 model of the Nintendo Switch (I used to have one but I sold it years ago).

The V1 Switch (Almost all Switch devices released pre August 2019) has a custom Nvidia processor, the Tegra X1, which came with a Recovery Mode (RCM for short). We can trigger this RCM and use it to flash custom firmware, linux and android. For the sake of this article we will focus on the custom firmware (CFW for short).

The First Step

First we need a jig, a little piece of plastic that fits in the right joycon rail which will bridge pin 1 and 10. These can be ordered very easily online when searching for Switch Jig. We also need an USB-A to USB-C cable or an USB-C to USB-C cable (this depends on if your computer has a USB-C port). We can also use an Android phone with the Rekado app installed.

Before we do this we do need to have an SD Card (I recommend at least an 128GB SD Card or more) ready with a couple of files. The community had a lot of different homebrew and files we could use back in the day, but it became a lot simpler now thanks to the HATS pack by Sthetix

We can enter RCM mode by having the jig in the right joycon rail and then pressing down on the volume up button and power at the same time. Release the power button while holding the volume up button and plug the cable in your Switch. The other end of the cable should already be in your computer or phone.

Installing all the packages

When everything is done correctly we should be able to see the Hekate/Nyx menu. From here we want to make a copy of our NAND chip in case anything goes wrong. Then we partition the SD Card to our liking and copy the backup over to the SD Card. Now we have HOS (Horizon OS) backed up and also copied to the SD Card. Keep this backup somewhere safe like an USB stick (cold storage) or on a NAS/Cloud.

  • Now there are a couple of ways of launching the Switch. I recommend mostly staying on CFW and avoiding the others if possible.
  • Nintendo actively monitors the device at all times when it is connected to the internet, but it will also collect data offline and send it to the servers when it connects to the internet again, resulting in a ban

When booted into CFW it looks like a regular Switch system but when inspecting the system info settings you will see it is now launched with Athmosphere, allowing for arbitrary code to be run on the device (homebrew, pirated games, etc.)

Last Steps

If we hold the R button when launching a game the Switch will enter Title Takeover mode and run the Homebrew menu instead of the game.

From here we can install custom themes, change the joycon color, install different Homebrew and install games.
