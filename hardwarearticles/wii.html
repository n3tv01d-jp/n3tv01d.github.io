Nintendo Wii Modding

Written by N3TV01D | Published September 22, 2026

Full Freedom on Bought Hardware

Console gaming is amazing, but I like having full control over every device that I have. Modding games to add characters that don't belong, downloading modpacks for games like Smash Bros to add or change content, running homebrew, managing save files and making backups of games I have.

This was the first modification I have ever made to a console and my dad wasn't to happy about it at first, but he ended up thinking it was a genius move. All it requires is an SD Card loaded with a couple of files.

The First Step

First we get a couple of files from the letterbomb website. All we need to enter on this website is the version of our system and the MAC Address, then we cut the red wire and we get our package.

Put all the files on the SD Card and insert the card into the Wii. Go to the message board in scroll back 2 days. There should now be a big red letter with a bomb inside it.

Installing all the packages

After having clicked the red letter we now choose to continue to install all required software. When prompted for the option to install the homebrew channel choose yes. Now we choose the BootMii option and choose Install BootMii as IOS. Press "Yes, continue" twice and then we get the option to "Install BootMii as boot2". Do this aswell. Now select "Return to the main menu" and select exit.

The Wii will now boot into the Homebrew Channel.

Final Steps

For safety reasons (we do not want the console to get bricked at any point in time) I recommend backing up the Wii NAND chip which has the operating system.
