Building a Network Scanner with BJORN

Written by N3TV01D | Published September 22, 2026

An Internal Automated Network Scanner

With a pwnagotchi you can obtain pcap packets to crack the WIFI password which is pretty useful. But once inside the network it would be nice to scan all connected devices for vulnerabilities. This is where BJORN comes in. BJORN is an network scanner that checks all devices for open ports or weak passwords. It is build on the same hardware fundamentals as a pwnagotchi which makes it pretty easy to just change SD Cards and have the same device do totally different things.

Building this device is as easy as the pwnagotchi and only takes about a few minutes of actual work. Most of the time put in this project is wasted on writing the image to the SD Card and installing the script.

The First Step

The first step is installing the 32bit version of Raspberry Pi OS Lite which can be written to the SD Card using the RPI-Imager. This might take a while but it is fundamental for this project. Configure a username, password, WIFI network and ssh settings so we can access the device in the next step.

When the installation is complete we want to give the device power and use ssh to connect into the device.

Installing all the packages

Now we want to install the BJORN script which can easily be done with the next 2 commands that we can find on the official github repository.

  • wget https://raw.githubusercontent.com/infinition/Bjorn/refs/heads/main/install_bjorn.sh
  • sudo chmod +x install_bjorn.sh && sudo ./install_bjorn.sh

After the installation is done we want to reboot the device. When rebooting the device the Waveshare Display will show a little Tamagotchi like Viking.

Final Steps

Now we can connect it to a network and it will automatically probe all connected devices.

Any configuration changes can be made in /home/bjorn/Bjorn/config/shared_config.json
