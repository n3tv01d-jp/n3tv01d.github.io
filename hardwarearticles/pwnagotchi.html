Building a WIFI Packet Sniffer with Pwnagotchi

Written by N3TV01D | Published September 22, 2026

An RPI Zero W and a Waveshare display

I think my WIFI password is pretty secure but better safe then sorry. So I decided I want to build a pwnagotchi. A pwnagotchi is a little Tamagotchi like device that feeds itself on captured pcap packets from WIFI networks. It works by deauthing every device on a network and when that device wants to reconnect the pwnagotchi captures the packets being moved between the device and the router/modem. It stores all these packets on an SD Card which we can later crack using hashcat for example.

DISCLAIMER: Of course this can be used maliciously too which I do NOT recommend since this is considered breaking the law in most countries. Hack responsibly!

The First Step

We will need an RPI Zero W (Zero 2 is even better) and a Waveshare V2 display (V1 has a lot of image ghosting and the V3 and V4 are not officially supported). Click the Waveshare Display on the RPI Zero pinout. Now all we've gotta do is flash the image to the SD Card.

Preferably you use a lithium battery pack to power the device, but having a 20.000mah powerbank works too. With a 10.000mah battery you have around 17 hours of runtime so 20.000mah will have about 34 hours of runtime.

Installing all the packages

Download BalenaEtcher from the official site and download the Pwnagotchi from the official github repository. Insert the SD Card into a laptop or desktop and write the pwnagotchi image to the SD Card. After doing so put the SD Card into the PI Zero and connect a power supply.

  • There are a lot of configurations that can be made inside the config.toml.
  • To configure the tamagotchi use the USB port instead of the power port and connect it to a laptop or desktop.

The instant it turned on, I was greeted by a Tamagotchi like face and I was ready to test it on my own network.

Final word

We can now test any and all WIFI passwords by deauthing a device from the network and capturing the packets.

As said before, only do this when you have the permission to do so. Hack responsibly!
