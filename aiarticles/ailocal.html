Running AI locally using Ollama

Written by N3TV01D | Published September 22, 2026

The Freedom of Local AI

Almost everyone uses AI today. Having ChatGPT installed on their phone, using Siri or Gemini on their Apple or Android device, even when googling something you get an automated response from an AI. The thing with these corporate AI's is that they keep all of your data. What you've been asking, account details, IP logging etc. I do not like this one bit so I decided it was time to build my own locally running AI machine.

With a lot of spare parts I still had laying around my house I was able to build a pc with 16GB of ram, a 6 core 12 threads processor and a dual RTX 3060 GPU setup. I installed a 500GB NVME drive with Ubuntu Server and installed the NVIDIA drivers. Now it was time to really get this thing going.

The First Step: Ollama

The first step is installing Ollama. We can do this with a one-line command that can be found on the official website ollama.com/download

This is a mostly automated process so it won't need a lot of configuration. But using Ollama from just the terminal doesn't look very nice.

Installing a front-end interface

Ollama itself is just a piece of software that can be run from the terminal but I want it to look nice. YouTuber PewDiePie has a github repo with a nice looking interface that is currently being maintained by a large community. The interface may be vibecoded but if we keep it local without it touching the internet it should be safe (referring to the Wireguard Setup so we can still access it from outside the network)

The github repo has a nice and quick install guide on the mainpage that makes this process surprisingly simple and easy which can be found here

For the installation of the Odysseus front-end we will need docker. For an easy install based on your distro of choosing I refer to the docker install guide here

Final Steps

Create a user account on the local web interface for Odysseus and inside the settings link the existing Ollama instance.

Now we can pull (abliterated) models from HuggingFace inside Ollama and they will automatically show up in the Odysseus interface. Be responsible however!
