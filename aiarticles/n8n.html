Using N8N for Automated Scheduling

Written by N3TV01D | Published September 22, 2026

The Magic of Automated Reminders

So right now I have setup an AI with a web interface and I have connected it to my Home Assistant so I can talk with it on my phone. I still want to get more productivity out of it so I decided I want to make a Telegram bot that will make appointments for me in my Google Calendar and remind me of those appointments on the day of said appointment.

We can setup N8N in multiple ways, we can use the cloud which eventually needs to be paid when we have more then 1 shared project. We can also use the install script that is linked on the official github or use docker to instantly setup a container. In my opinion docker seems to be the best for my use case but I don't want to simply use the docker run container command provided on the github page so let's do something else.

I have made my own docker-compose.yml which can be downloaded here

The Next Step

After having made the docker-compose.yml we can use the sudo docker compose up -d --build command to launch the N8N instance. We make an account and are greeted by the interface. From here you can make a new project and automate nearly anything you'd like. In this case it is a Telegram Bot which does need a couple of things.

The N8N Server needs to have port 80 and 443 forwarded, it also needs SSL Certification or else the Telegram Bot will not work.

To do this (without paying money) we head to noip.com and make an account. Have the public IP of your network routed to a subdomain of your choosing. After that we install certbot on our server with sudo apt install certbot so we can get a free SSL Certification and we need nginx sudo apt install nginxto make a reverse proxy so our N8N instance can be hosted to the clear net.

We need to configure certbot to use the domain name that we got from noip and we need to configure nginx as a reverse proxy to our N8N instance. The quickest guide can be found here

Getting a Telegram Bot

Getting a Telegram Bot setup is pretty easy. Below are the steps for getting your own Telegram Bot

  • Message the BotFather on Telegram with /start
  • Make a new bot with the /newbot command
  • Give the bot a name and a username
  • You will now get your Bot Token, paste this token inside the N8N Telegram Nodes

Configure the Google Calendar API, get a token and paste it in the Google Calendar node and hook the node to the AI Agent node. The quickest guide can be found here

The Final Steps

Get your Telegram Bot API and place it inside of the Telegram Nodes inside N8N.

If all is well you should now be able to have your local Ollama instance make appointments for you and remind you of your appointments.
