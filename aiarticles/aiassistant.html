Building a Plex Media Server

Written by N3TV01D | Published September 22, 2026

The Magic of One Mini PC

A few months ago, I decided I wanted to rewatch some of the anime I used to watch as a kid. My younger sisters boyfriend had setup a Plex Server in the past which looked pretty impressive so I decided that I should do the same.

Utilizing a few docker containers you can build your very own local container network that is able to pull and stream TV series, movies and music, all neatly packed on 1 system using docker compose.

The First Step

The first step in any project is indexing what you need. We start off by installing docker using the correct method for your distribution of Linux which can be found on https://docs.docker.com/engine/install/

Once docker has been installed we need the following packages: Deluge, Prowlarr, Sonarr, Radarr, Overseerr, Plex, Sabnzbd and Lidarr (optional for music). These packages exist on the Docker Hub and are being maintained by LinuxServer lscr.io

Installing all the packages

Now that we've indexed what we need it is time to put it all together. Using a docker-compose.yml we are able to neatly package it all together and launch it as a cluster of containers

  • A preview of the docker compose file can be found here:
  • Run the containers using the command sudo docker compose up -d --build

The instant I turned it on, multiple locally hosted sites became accessible on the local ip and port, for example 192.168.178.225:8686.

Next Steps

Now that we have the containers up and running there is only 1 thing to do: configuring all the containers by going to the ip of the machine followed by the port of the service. (These can be found in the docker-compose.yml)

Link all the containers together using the web interfaces, claim the server to an existing Plex Account and watch as much as you want.
