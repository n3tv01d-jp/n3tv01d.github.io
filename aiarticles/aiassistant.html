AI Assistant using Ollama and Home Assistant

Written by N3TV01D | Published September 22, 2026

A Raspberry Pi and an AI Server

In the previously written article we installed an Ollama instance with a front-end interface. Today we are gonna hook that same Ollama instance up to an Home Assistant installation so we can speak to an AI assistant like Google's Gemini on an Android phone.

Utilizing a Raspberry Pi you can build your very own Home Assistant network that is able to activate and respond based on a wakeword. When this wakeword is triggered (For example "Hey Google" or "Okay Nabu") we can talk with the AI and it will respond back using the piper and whisper library's. Setting this up is a little more complicated than Odysseus from the previous article but it should still be a intermediary project that's quite easily done.

The First Step

The first step is flashing Home Assistant to an SD Card. We start off by downloading the Raspberry Pi Imager with sudo apt install rpi-imager and then we flash the Home Assistant image to the SD Card.

Once Home Assistant has been flashed to the SD Card we put the SD Card into the RPI 5 and connect an ethernet cable and power supply to it. After this we are able to visit the local ip of the device in a browser and configure the Home Assistant installation.

Installing all the packages

Now we install the openwakeword, piper and whisper library's through the app section of the Home Assistant interface. We also download the Ollama integration and hook it up to the Ollama instance we installed on the AI Server.

  • These intergrations might need a little bit of tinkering for them to work.
  • You can see the debug console for any errors in case something is not working as intended.

At last we install the Home Assistant app on our phone and proceed to connect it to the Home Assistant server we are currently running.

Final Steps

We configure which model we want to use and what our wakeword will be. I choose for "Okay Nabu" due to personal preferences.

We are now able to call the AI with the wakeword we choose and proceed to ask it questions. With more integrations which we can install through the Home Assistant interface we can ask the AI what the weather will be like or what time it is and it will use the integrations to give us accurate information.
